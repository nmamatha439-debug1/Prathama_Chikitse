# Prathama Chikitsa App

## Project Overview
Prathama Chikitsa is an Android application developed using Android Studio.  
The app helps users during emergency situations by providing first-aid guidance.

## Features
- User Login Page
- Emergency Call Button
- Dashboard with Emergency Situations:
  - Heart Attack
  - Snake Bite
  - Choking
  - Electrical Shock
  - Fracture
  - Burns
- Instructions on:
  - What To Do
  - What Not To Do
- Settings Screen
- User Information Storage
- Logout Option

## Technologies Used
- Kotlin
- Android Studio


## Purpose of the Project
The purpose of this application is to provide quick first-aid information and emergency support during acute emergency situations.
